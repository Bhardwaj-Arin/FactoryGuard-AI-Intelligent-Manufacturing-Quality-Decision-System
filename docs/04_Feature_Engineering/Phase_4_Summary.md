# Phase 4 — Feature Engineering Summary

## Overview

Phase 4 converted the dataset analyzed during EDA into a structured machine-learning-ready feature set for FactoryGuard AI.

The phase focused on feature validity, preprocessing, feature creation, feature selection, and preparation for model development.

---

## Objectives

The main objectives were:

- Prevent target leakage
- Evaluate identifier features
- Define predictor and target variables
- Split data into training and testing sets
- Handle missing values
- Encode categorical features
- Assess numerical features
- Evaluate outliers and skewness
- Create meaningful manufacturing features
- Analyze feature redundancy
- Build a reproducible preprocessing pipeline
- Define a class-imbalance strategy
- Validate the final feature set
